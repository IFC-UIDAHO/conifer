# Citation

If you use CONIFER, please cite the software. The methodology manuscript is **in preparation**; this page
will be updated with the paper's DOI on publication.

## Software

Machine-readable metadata is in [`CITATION.cff`](https://github.com/IFC-UIDAHO/conifer/blob/main/CITATION.cff)
at the repository root (GitHub renders a "Cite this repository" button from it).

```bibtex
@software{conifer,
  author  = {Poolakkal, Jaslam},
  title   = {{CONIFER}: Compositional, design-aware small-area estimation
             of forest diameter distributions with conformal prediction sets},
  year    = {2026},
  url     = {https://github.com/IFC-UIDAHO/conifer},
  note    = {Python package \texttt{conifer-sae}; methodology manuscript in preparation},
  organization = {Intermountain Forestry Cooperative, University of Idaho}
}
```

## Methodology manuscript

> *Methodology manuscript in preparation.* Releasing the software ahead of the paper is standard practice in
> statistics and scientific computing: it lets reviewers run the method, surfaces bugs early, and supports
> reproducibility. Most journals do not treat a software release as prior publication.

Once the paper is published, cite **both** the paper (for the method) and the software (for the
implementation and version used).
